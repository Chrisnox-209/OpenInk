# OpenInk 1.7.0 · Windows et macOS — préversions non testées

> [!WARNING]
> **WINDOWS ET macOS NON TESTÉS SUR LEURS SYSTÈMES NATIFS.**
> Ces portages sont expérimentaux. Leur bon fonctionnement n’est pas garanti.
> Windows a été vérifié uniquement sous Wine/Linux ; le kit macOS n’a été ni
> compilé ni exécuté sur un Mac. Les simulations ne valident pas l’USB,
> l’impression papier, les notifications natives ou le flash sur ces systèmes.

Lire [l’avertissement complet — français / English / español](https://github.com/Chrisnox-209/OpenInk/blob/main/DISCLAIMER.md).

## Windows

Extraire tout le ZIP, puis ouvrir `OpenInk.exe`. Garder `_internal` à côté.
La fermeture de la fenêtre conserve l’agent et l’icône ; leur menu permet
d’arrêter le suivi. La signature numérique et les tests sur Windows réel
ne sont pas fournis dans cette bêta.

[Guide Windows](https://github.com/Chrisnox-209/OpenInk/blob/main/windows/README.md).

## macOS

Installer Python 3.14 avec Tkinter, extraire le kit et ouvrir
`macos/Lancer-OpenInk.command`. Les dépendances Intel et Apple Silicon sont
incluses. Pour construire un `.app` autonome sur le Mac, installer les outils
en ligne de commande Apple puis ouvrir `macos/Installer-OpenInk.command`.
Le résultat local est signé « ad hoc », sans notarisation Apple.

[Guide macOS](https://github.com/Chrisnox-209/OpenInk/blob/main/macos/README.md).

## Vérifications et limites

- Socle Linux : 117 tests hors ligne réussis.
- Windows : 23 tests logiciels et démarrage de l’exécutable vérifiés sous Wine,
  ainsi que l’agent, l’icône et une notification sur un écran virtuel.
  Aucune imprimante n’a été commandée pendant ces vérifications.
- macOS : 21 tests simulés sous Linux et vérification des dépendances pour
  chaque architecture. Aucune compilation, signature ou exécution sur un Mac.
- Interface : 30 combinaisons de vues/langues/thèmes contrôlées pour chaque
  portage dans les environnements de préparation. Cela ne valide pas Aqua
  ni une session Windows native.

**Le flash OpenFlow sur Windows/macOS reste non validé et peut bloquer
l’imprimante.** Conserver les sauvegardes et ne pas considérer ces parcours
comme validés pour une opération réelle. L’image V2 historique reste inchangée.
Installer ou lancer OpenInk ne déclenche aucun flash.

La version Ubuntu stable reste disponible dans la publication
[v1.7.0](https://github.com/Chrisnox-209/OpenInk/releases/tag/v1.7.0).

**English:** Windows and macOS ports are experimental and untested on their
native operating systems. Windows checks used Wine only. macOS includes a
source installation kit, not a built app. Real USB, printing, native notifications
and firmware flashing remain unvalidated.
