# OpenInk 1.5.0 · Ubuntu

- Icône dans le panneau Ubuntu et démarrage automatique sans fenêtre.
- Menu pour ouvrir OpenInk, consulter les compteurs, actualiser et arrêter le suivi.
- Nouvelle goutte CMJN, icônes du dock et page de test mises à jour.
- Barre latérale attachée au bord gauche et contenu adapté à la largeur disponible.
- Firmware renommé **OpenFlow**, avec avertissement de flash mis en évidence.
- Page de test corrigée : files CUPS désactivées identifiées, file disponible
  présélectionnée, confirmation claire et état relu avant soumission.
- Version affichée 1.5.0 et présentation du README simplifiée.

## Installer

Télécharger `openink_1.5.0_amd64.deb` et `SHA256SUMS` dans le même dossier,
fermer l’ancienne fenêtre puis exécuter :

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./openink_1.5.0_amd64.deb
openink
```

Poursuivre après un résultat `OK`. Les données existantes sont conservées.
Le suivi reste actif quand la fenêtre est fermée. L’option de démarrage en
mode icône est disponible dans Réglages.

**Cette mise à jour ne nécessite aucun flash. OpenFlow utilise exactement
l’image V2 déjà fournie ; seul son nom change.** L’assistant conserve les
confirmations de risque et d’USB obligatoire, les sauvegardes et les contrôles.

## Validation

101 tests hors ligne réussis, contrôle graphique des cinq vues et du dialogue
d’impression, intégration réelle sur D-Bus isolé. Une seule page de test a été
envoyée à l’Epson : CUPS l’a terminée et le compteur couleur a augmenté d’une page.
Aucun flash n’a été effectué.

Les niveaux restent estimatifs et ne garantissent pas l’absence de désamorçage.
La disponibilité de l’icône dépend du support des indicateurs par le panneau.
