# OpenInk 1.4.0-beta1 · Ubuntu

Première préversion Linux publiée depuis le dépôt OpenInk. Elle contient
l’application Tkinter, son agent de surveillance, les notifications Ubuntu,
le suivi indicatif par couleur et l’assistant V2 par USB.

## Fichiers à télécharger

- `openink_1.4.0-beta1_amd64.deb` : paquet Ubuntu x86_64, prêt à installer.
- `OpenInk-Ubuntu-1.4-beta1-sources.tar.gz` : sources autonomes, tests, ressources
  et documentation, avec manifeste d’empreintes intégré.
- `SHA256SUMS` : empreintes SHA-256 des deux fichiers précédents.

## Installation

Télécharger le `.deb` et `SHA256SUMS` dans le même dossier. Fermer l’ancienne
application et exécuter depuis ce dossier :

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./openink_1.4.0-beta1_amd64.deb
openink
```

Poursuivre seulement si le paquet affiche `OK`. Le paquet remplace Inkora et
conserve les données utilisateur. Utiliser `openink --demo` pour un aperçu
isolé de l’imprimante. La mise à jour du logiciel ne déclenche aucun flash ;
une V2 déjà installée n’a pas à être reflashée.

## Fonctionnalités

- Identité OpenInk, logo CMJN vectoriel et fenêtre adaptée au moniteur.
- Niveaux estimés par couleur, profils 604/604XL et historique local.
- Préalerte à 30 %, réserve à 20 %, seuils réglables et notifications de session.
- Bouton de page de test A4 avec logo, motifs CMJN et choix explicite de file CUPS.
- Assistant V2 avec pourcentage par étape, acceptation des risques et USB obligatoire.
- Contrôle ciblé après retour USB confirmé, avec repli prudent si le résultat est incertain.

## Validation et limites

Les 90 tests hors ligne passent. Le paquet et l’archive ont été construits
depuis le dépôt autonome ; leur contenu a été comparé au tag de publication.

Version **bêta**, limitée à la XP-2200 IU05P2 compatible. Le flash reste global :
il ne réécrit pas les puces et ne sélectionne pas une couleur à réinitialiser.
Les 100 % Epson sous V2 sont simulés ; les niveaux OpenInk restent indicatifs
et ne garantissent pas l’absence de désamorçage.

La détection anticipée du redémarrage a été testée en simulation. Le contrôle
ciblé a été exécuté en lecture seule sur une V2 réelle en 32,26 secondes.
Aucun nouveau flash n’a été réalisé pour cette publication.

Avant toute opération firmware : USB direct, alimentation stable et sauvegarde
préalable. Ne pas imprimer ou débrancher pendant l’opération. Un incident peut
rendre l’appareil inutilisable ; les confirmations de l’assistant restent requises.

Le dépôt et cette préversion restent **privés**. Les sauvegardes personnelles,
fichiers de récupération et identités réelles d’imprimantes sont exclus.
