# OpenInk 1.7.0 · Ubuntu

- Nouvel encart **Apparence** : langue et choix **Clair / Sombre**.
- Vrai thème sombre en gris anthracite inspiré de Discord, appliqué aux cinq
  vues, menus, champs et dialogues.
- Choix conservés au prochain lancement, en français, anglais et espagnol.
- Interrupteur **Lancer minimisé à la connexion**, utilisable à la souris et au clavier.
- Bouton **? bleu** expliquant l’historique et les alertes en arrière-plan.
- Guides et captures actualisés dans les trois langues.

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./openink_1.7.0_amd64.deb
openink
```

L’interrupteur concerne les prochaines connexions Ubuntu. Désactiver le lancement
automatique ne coupe pas le suivi en cours. OpenInk peut toujours être ouvert
manuellement pour reprendre la surveillance.

**Les données sont conservées. Aucun nouveau flash n’est nécessaire.**

Validation : 117 tests hors ligne et vérifications graphiques dans les deux thèmes
et les trois langues. Aucun flash ni travail d’impression réel pour cette version.
