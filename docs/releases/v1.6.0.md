# OpenInk 1.6.0 · Ubuntu

- Programme en français, anglais et espagnol : interface, panneau,
  notifications, diagnostics et avertissements de flash.
- Choix de langue enregistré dans Réglages et option `--lang`.
- Pages de test PDF traduites.
- README principal français et guides complets anglais/espagnol, illustrés
  par des captures de chaque langue.
- Explication du flash OpenFlow pour les cartouches compatibles rejetées
  et du suivi indicatif de l’encre après installation.
- Suppression du mode démonstration des commandes publiques.

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./openink_1.6.0_amd64.deb
openink
```

La mise à jour conserve les données. Choisir la langue dans Réglages ou lancer
`openink --lang fr`, `openink --lang en`, `openink --lang es`.

**L’image firmware reste inchangée. Aucun nouveau flash n’est nécessaire.**
Les confirmations de risques et de connexion USB restent obligatoires pour
une installation OpenFlow. Les niveaux d’encre restent estimatifs.

Validation : 113 tests hors ligne, cinq vues dans chacune des trois langues,
menu du panneau testé sur D-Bus isolé, neuf captures et trois PDF vérifiés.
Aucun flash ni travail d’impression réel n’a été effectué pour cette version.
